# Activation Modeling v2.5

This directory contains Lean stubs defining mathematical activation models,
activation model trajectories, activation model invariants, and activation model
outcomes. These functions model activation conditions mathematically without
performing activation.

## Included Modeling Stubs

### Lean
- ActivationModel
- activationModel
- activationModelInvariantsSatisfied
- activationModelTrajectory
- activationModelOutcome
- activationModelKernel
- activationModelReport

These stubs will be expanded in v2.6 to support activation semantics and
deterministic activation interpretation.
