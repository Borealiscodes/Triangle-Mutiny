# Activation Logic v2.0

This directory contains Lean stubs for the activation kernel, activation
invariants, and activation surfaces. These functions define the structural
conditions under which activation could occur, but do not perform activation.

## Included Activation Logic Stubs

### Lean
- activationInvariantStable
- activationInvariantSpectral
- activationInvariantCollapse
- activationInvariantsSatisfied
- activationSurfaceStable
- activationSurfaceSpectral
- activationSurfaceCollapse
- activationKernel
- activationReport

These stubs will be expanded in v2.1 to support activation transitions and
geometric activation surfaces.
