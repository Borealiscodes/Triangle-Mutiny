# Activation Transitions v2.2

This directory contains Lean stubs defining activation transition legality,
transition invariants, transition geometry, and the transition kernel. These
functions define how activation would move across geometric surfaces without
performing activation.

## Included Transition Stubs

### Lean
- transitionLegal
- transitionInvariantStable
- transitionInvariantSpectral
- transitionInvariantCollapse
- transitionInvariantsSatisfied
- transitionGeometryStable
- transitionGeometrySpectral
- transitionGeometryCollapse
- transitionGeometryDrift
- transitionGeometryModal
- transitionGeometryClear
- activationTransitionKernel
- activationTransitionReport

These stubs will be expanded in v2.3 to support activation simulation and
deterministic activation pathways.
