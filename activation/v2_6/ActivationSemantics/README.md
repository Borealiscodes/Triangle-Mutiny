# Activation Semantics v2.6

This directory contains Lean stubs defining semantic activation descriptors,
semantic activation interpretations, and the semantic activation kernel. These
functions describe activation conditions semantically without performing
activation.

## Included Semantics Stubs

### Lean
- ActivationSemantics
- activationSemantics
- activationSemanticInterpretation
- activationSemanticKernel
- activationSemanticReport

These stubs will be expanded in v2.7 to support activation algebra and
deterministic activation formalization.
