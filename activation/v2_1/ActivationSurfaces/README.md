# Activation Surface Geometry v2.1

This directory contains Lean stubs defining geometric activation surfaces.
These surfaces represent the geometric conditions that must be satisfied for
activation transitions to be considered in future versions.

## Included Activation Surface Stubs

### Lean
- activationSurfaceStability
- activationSurfaceSpectral
- activationSurfaceCollapse
- activationSurfaceDrift
- activationSurfaceModal
- allActivationSurfacesClear
- activationSurfaceReport

These stubs will be expanded in v2.2 to support activation transition geometry
and activation surface traversal logic.
