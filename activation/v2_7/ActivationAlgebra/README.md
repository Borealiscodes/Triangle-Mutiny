# Activation Algebra v2.7

This directory contains Lean stubs defining algebraic activation operators,
relations, bundles, invariants, and algebraic kernel. These functions formalize
activation conditions algebraically without performing activation.

## Included Algebra Stubs

### Lean
- activationOp
- activationRelation
- ActivationBundle
- activationBundle
- activationAlgebraInvariantsSatisfied
- activationAlgebraKernel
- activationAlgebraReport

These stubs will be expanded in v2.8 to support activation formalism and
axiomatic activation structure.
