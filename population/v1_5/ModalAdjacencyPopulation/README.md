# Modal Adjacency Population v1.5

This directory contains the initial Lean and Rust stubs for modal adjacency.
Modal adjacency defines which reasoning modes may legally transition to one
another and prevents semantic teleportation.

## Included Modal Adjacency Stubs

### Lean
- Mode (enum)
- isAdjacent
- legalTransition
- modalDistance
- modalStable

### Rust
- Mode (enum)
- is_adjacent
- legal_transition
- modal_distance
- modal_stable

These stubs will be populated with real adjacency logic in v1.6 and v1.7 once
activation geometry validates the system.
