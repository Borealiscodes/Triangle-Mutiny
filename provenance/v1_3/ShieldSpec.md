# Triangle Mutiny — Provenance Shield (v1.3)
## ShieldSpec.md

The Provenance Shield enforces deterministic lineage across all reasoning
transitions. It records invariant evaluations, stability classifications,
collapse-surface interactions, and drift accumulation.

### Responsibilities
- Record invariant evaluations
- Record stability envelope classification
- Record spectral mismatch and curvature deltas
- Record modal adjacency decisions
- Record drift tensor norms
- Record collapse-surface interactions
- Produce immutable audit trail entries
- Integrate with Rust runtime and deterministic kernel

### Shield Input
- RuntimeState
- invariant results
- stability classification
- collapse predicate results

### Shield Output
- ProvenanceRecord
- AuditTrailEntry
