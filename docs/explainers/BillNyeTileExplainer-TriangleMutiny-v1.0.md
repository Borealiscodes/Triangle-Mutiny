🧱 Tile 1 — We Built a Geometry for Reasoning
Think of reasoning like a marble rolling on a weird, twisty surface.  
We built the rules for that surface:

- Curvature = how sharply the surface bends  
- Spectral structure = how the marble reacts to local forces  
- Modal labels = what “zone” the marble is in  
- Drift = how the marble tends to slide  

This is the Math Spine v1.2 — the laws of physics for reasoning.
